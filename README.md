# 기자재 대여·반출

Stitch 시안을 바탕으로 만든 PC·모바일 반응형 기자재 대여 웹의 첫 검토 버전입니다.

## 실행

Node.js 22 이상에서:

```sh
cd web
npm ci
npm run dev
```

## 구현한 기능

- 학번·이름·학년·수업명·담당 교수 입력 및 검증
- 입력 내용 자동 저장, 3단계 신청, 교내/교외 사용 구분
- 기자재 검색·분류·선택·수량 조절
- 대여 기간별 최대 동시 예약량 계산 및 초과 신청 방지
- 신청 확인·제출·취소
- 담당자 목록 검색·상태 필터·CSV 내보내기
- 승인·반려(사유 필수)·인도·반납 및 처리 이력
- 학생/담당자별 웹 알림함, 읽음 처리, 알림에서 해당 신청 열기
- 같은 브라우저의 탭 간 변경 동기화, Web Locks 기반 동시 저장
- 지원 브라우저에서 권한 요청 및 테스트 시스템 알림
- PC 표와 상세 패널, 모바일 카드와 전체 화면 상세

## 현재 버전의 범위

**실제 운영용 서버가 연결된 버전이 아닙니다.** 화면 상단과 체험 설정에도 범위를 표시합니다.

- 데이터는 현재 브라우저의 localStorage에 저장합니다. 기기·브라우저 간 공유하지 않습니다.
- 학생/담당자 전환은 체험용이며 인증 또는 권한 검증이 아닙니다.
- 예시 기자재 및 예시 신청 정보는 검토를 위한 데이터입니다.
- 실제 학생의 개인정보를 입력하여 운영하는 용도로 사용하면 안 됩니다.
- 메일 발송은 사용자 요청에 따라 포함하지 않았습니다.
- 웹을 닫은 뒤의 서버 푸시/알림 예약 발송은 연결하지 않았습니다. 알림 권한과 service worker 기반 표시 기능만 제공합니다.
- 다른 탭이 열려 있고 알림 권한이 있는 경우, 같은 브라우저에서 발생한 해당 역할의 변경을 표시할 수 있습니다. 운영체제 알림 표시 여부는 기기 설정에도 따릅니다.

실제 공동 사용 단계에서는 서버 저장소, 학생/담당자 인증, 서버의 재고 트랜잭션 및 접근 제어, 푸시 구독 등록과 발송 작업이 필요합니다. 프런트엔드의 역할 전환을 운영 권한으로 사용하지 않습니다.

## 검증

```sh
cd web
npm run build
npm test
```

예약 충돌·수량·상태 전이·반려·취소·연체 재고 및 알림 생성 테스트를 포함합니다. 수동 브라우저 검증 결과는 `design-qa.md`에 기록합니다.

## 배포

`main`에 push하면 GitHub Actions가 빌드/테스트 후 GitHub Pages에 배포합니다. 배포 디렉터리는 `web/dist/client`입니다. 상대 경로와 hash navigation을 사용해 프로젝트 하위 경로에서도 동작합니다.

## 구성

- `web/src/App.jsx`: 화면·입력·상호작용
- `web/src/styles.css`: PC·모바일 디자인
- `web/src/domain.js`: 기자재·신청·재고·알림 규칙
- `web/src/repository.js`: 브라우저 저장 및 동시성 제어
- `web/public/sw.js`: 브라우저 알림 표시/클릭 처리
- `web/public/equipment`: 사용자 제공 Stitch 시안의 이미지
- `.github/workflows/deploy.yml`: GitHub Pages 자동 배포
